### ✨ Modern Jewelry E-Commerce Website

A modern, elegant, and fully responsive jewelry website built with **HTML5, Tailwind CSS, CSS3, and JavaScript**.

Cignet Jewelry focuses on luxury aesthetics, clean layouts, smooth interactions, and a high-end shopping experience.

---

## 🛠️ Built With

* **HTML5** — Semantic website structure
* **Tailwind CSS** — Utility-first CSS framework used to build the complete responsive UI
* **CSS3** — Custom animations, transitions, and visual effects
* **JavaScript** — Interactive functionality
* **Font Awesome** — Icons

---

## 🎨 Tailwind CSS

This project is built using **Tailwind CSS** with a utility-first approach.

Tailwind classes are used throughout the website to handle:

* 📐 Layout & positioning
* 📱 Responsive breakpoints
* 🎨 Colors & backgrounds
* ✍️ Typography
* 📏 Spacing & sizing
* 🧩 Flexbox & Grid
* ✨ Hover states
* 🎬 Transitions & animations
* 🖥️ Desktop / Tablet / Mobile layouts

The website is designed to be fully responsive using Tailwind's responsive utilities such as:

```html
sm:
md:
lg:
xl:
2xl:
```

---

## 📱 Responsive Design

Cignet Jewelry is fully responsive and optimized for:

📱 **Mobile**

💻 **Tablet**

🖥️ **Desktop**

The layout is implemented primarily with **Tailwind CSS responsive utilities**, allowing sections, grids, navigation, typography, spacing, and product cards to adapt smoothly across different screen sizes.
